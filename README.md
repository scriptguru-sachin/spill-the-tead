# Spill the Tea

An AI learning studio that turns difficult topics into fact-grounded, gossip-style stories. The repository intentionally keeps the applications separate:

- `client/` — React + Vite frontend (safe to hand to a frontend collaborator)
- `backend/` — Laravel 13 JSON API
- PostgreSQL 17 — provided through Docker Compose

## Run everything

1. Copy `backend/.env.example` to `backend/.env` and set `GEMINI_API_KEY`.
2. Start Laravel and PostgreSQL: `docker compose up --build`
3. In another terminal run `cd client && npm install && npm run dev`.

The API is at `http://localhost:8000/api`; migrations run when the API container starts. Vite proxies `/api` to Laravel. For a separately hosted frontend, copy `client/.env.example` to `client/.env` and set `VITE_API_URL`.

## API contract

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `GET` | `/api/health` | Service health |
| `GET` | `/api/lessons?client_id={uuid}` | Recent lesson history |
| `POST` | `/api/lessons` | Generate and persist a lesson |
| `GET` | `/api/lessons/{id}` | Retrieve a lesson |
| `POST` | `/api/lessons/{id}/quiz-attempts` | Score and persist a quiz attempt |
| `POST` | `/api/lessons/{id}/feedback` | Save lesson feedback |
| `GET/POST` | `/api/lessons/{id}/doubts` | Load or save message-level doubts |
| `POST` | `/api/lessons/{id}/follow-ups` | Generate an adaptive sequel |

Create lesson body:

```json
{
  "client_id": "a UUID generated by the frontend",
  "topic": "Why does Redis make apps faster?",
  "level": "Beginner",
  "format": "Group chat",
  "drama": 3
}
```

Levels: `Auto`, `Beginner`, `Intermediate`, `Advanced`. `Auto` uses the learner's latest five quiz attempts. Formats: `Group chat`, `Courtroom debate`, `Reality show`, `Interview`. Drama is 1–5.

Lessons use Gemini Google Search grounding and retain the returned citation metadata. Search grounding consumes the Gemini project's search quota and may require available billing/quota. Follow-up modes are `weak_spots`, `go_deeper`, `practical`, and `compare`; each generated sequel is linked to its parent lesson.

## Verify

```bash
docker compose exec api php artisan test
cd client && npm run build
```

The old Express implementation remains in `server/` as migration reference only. The active client targets Laravel on port 8000.
